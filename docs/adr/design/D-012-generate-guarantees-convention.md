# D-012 生成保證照分層慣例：斜坡不合格就擋下

## 當前情境

- 慣例檢查（#50）照 WeftEngine 的地形規則查斜坡：斜坡的每一格，北東南西至少一格剛好高一階，不然引擎報內容錯誤。
- 生成不保證這件事：規則把斜坡種類畫成一塊，只有貼著高處的那一排合格（#56）。
- 情境：`ramp` 是 3×2，貼著兩階的小丘，生成後 5 格被檢查報出來。

## 選擇

| 選項 | 適合 | 代價 |
|---|---|---|
| 生成時擋下（選中） | 生成的地圖一定照慣例，引擎讀得進；跟「排不下就報錯」一致 | 寫規則要知道斜坡只能一格深（或一階一階疊）；測試的規則產生器要只產生合格的斜坡 |
| 生成照做，摘要附上檢查結果 | 改得最少 | 可能生成出引擎報錯的地圖，靠讀摘要發現 |
| 維持現狀，只靠檢查操作 | 不用改 | 容易忘記查，進了遊戲才發現 |

## 決策

- 生成照規則畫完之後查斜坡；有一格不合格就丟 SceneError，磁碟上的檔不變。
- 訊息開頭是斜坡所在的元素，例如 `ramp.kind：斜坡格 (13,18) 四周沒有高一階的格`。
- 判斷跟慣例檢查同一條規則，寫在同一個地方，不各寫一份。
- 生成成功的場景地圖一律通過慣例檢查。

## 三個月後的影響

- 寬的坡道要寫成一格深、沿著高處排開，或一階一階疊起來。
- 慣例檢查再加新的規則時，生成要不要跟著保證，照這份的原則：要。
